Infrastructure Engineer & Homelab Enthusiast

I build and maintain infrastructure at home. Not because I have to, but because understanding how systems work at every layer makes me better at my job.

The Stack

Compute

  • Proxmox VE Cluster — 3-node cluster on Ceph distributed storage, running a dozen-plus VMs and LXC containers
  • AI/ML Workstation — RTX 3090, Ollama, and Open WebUI for private, local LLMs
  • Docker — 100+ containers across six hosts, managed with Portainer and Dockhand

Storage & Backup

  • Ceph — Replicated storage across the Proxmox cluster
  • Synology NAS — Primary media library and shared storage
  • UGREEN NAS — Four-bay array with mirrored NVMe for apps and containers
  • Proxmox Backup Server — Deduplicated VM and container backups
  • restic — Automated, monitored file-level backups

Network

  • UniFi Gateway Max — Routing and zone-based firewall
  • UniFi Switching & Wi-Fi — 13 managed switches and 3 access points
  • Technitium DNS — Redundant internal DNS with network-wide ad blocking
  • NetBox — Source of truth for hardware, IPs, and inventory

Self-Hosted Services

  • Jellyfin & Plex — Private media streaming
  • Nextcloud — Files and collaboration
  • Immich — Photo library
  • Home Assistant — Home automation
  • Frigate — NVR with AI object detection
  • Paperless-ngx — Document management
  • Mealie — Recipe management
  • n8n — Workflow automation

Observability

  • Prometheus & Grafana — Metrics and dashboards
  • Loki — Centralized logs
  • Alertmanager — Alerts that reach my phone when something breaks

Custom Projects

  • Jarvis — My digital personal assistant and second brain. An AI agent built on Claude Code and a 6,000-note Obsidian vault that helps monitor, document, and fix the lab.
  • Ripper — A purpose-built web app for my disc collection. MakeMKV, HandBrake, GPU encoding, and TMDb lookup take a DVD or Blu-ray from the drive to my media library.
  • AI-Assisted Development — Local LLMs, MCP servers for tool integration, and n8n workflows for building tools that solve real problems.

External Access

  • Pangolin — Self-hosted tunneled reverse proxy for external access
  • Traefik — Internal reverse proxy with native ACME
  • Tailscale — Private remote access
  • Let's Encrypt — Automated SSL everywhere

Security

  • Authentik — SSO and identity provider for internal services
  • Wazuh — Security monitoring
  • fail2ban — Brute force protection
  • Firewall Zones — IoT devices and cameras are segmented from anything important

Philosophy

  • Self-hosted over cloud-dependent — Own your data, understand your dependencies
  • Document everything — If it's not written down, it doesn't exist
  • Automate the repetitive — Earn back time for things that matter
  • Learn by building — Theory is nice, but hands-on is how it sticks
